RosaGen es un generador de números y caracteres aleatorios con salida hacia hexadecimal, se puede seleccionar la cantidad de elementos a generar, y si van a ser números aleatorios convertidos a hexadecimal, o caracteres aleatorios convertidos a hexadecimal, esto incluye caracteres no imprimibles, se puede usar en lugares donde se requieran contraseñas de muy alta seguridad, esta es la primera versión totalmente gratuita y de código libre.

Se llama RosaGen debido a que fué desarrollado desde 0 usando Rosa Linux 12.5.1 con escritorio Gnome aunque la aplñicación es modo consola.

En caso de ejecutar los archivos compilados no se requiere instalar nada, ya está todo listo para ejecutar y usar, está escrito en python 3.8.1 y compilado con pyinstaller

Si se quiere ejecutar directamente del script, nada más revisar que todas las dependencias están instalaadas (si se está usando una versión recortada del lenguaje de programación)

Se puede ejecutar incluso en Android usando QPyton3, nada más hay que copiarlo en el directorio de scripts de QPython3 y correrlo desde ahí

RosaGen is a random number and character generator with output to hexadecimal, you can select the number of elements to generate, and if they are going to be random numbers converted to hexadecimal, or random characters converted to hexadecimal, this includes non-printable characters, it can be used in places where very high security passwords are required, this is the first version that is completely free and open source.

It is called RosaGen because it was developed from scratch using Rosa Linux 12.5.1 with Gnome desktop although the application is in console mode.

If you run the compiled files, you don't need to install anything, everything is ready to run and use, it is written in Python 3.8.1 and compiled with pyinstaller

If you want to run it directly from the script, just check that all the dependencies are installed (if you are using a cut-down version of the programming language)

It can even be run on Android using QPyton3, just copy it to the QPython3 scripts directory and run it from there
